PREÇOS PELO MUNDO

Comparações de preços. Gestão do próprio canal.

O Preços Pelo Mundo compara preços e condições de compra em diferentes países, com informação contextualizada e linguagem de entretenimento.

Sobre o aplicativo

Esta ferramenta de uso restrito ao responsável pelo canal organiza vídeos aprovados, envia conteúdo ao YouTube e consulta resultados do próprio canal para orientar os próximos temas. Não é um serviço aberto ao público.

A conexão usa o login e a autorização oficiais do Google. O aplicativo utiliza os YouTube API Services, incluindo YouTube Data API e YouTube Analytics API. As tarefas agendadas funcionam no GitHub Actions.

Este site apresenta a ferramenta e suas políticas. Não solicita senhas nem recebe arquivos de credenciais. A conexão do canal acontece em uma página privada separada.
